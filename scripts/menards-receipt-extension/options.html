Menards Receipt Sync

Fetches receipts from Menards' own receipt-lookup endpoints using this browser's signed-in session, and posts them to Hive. Runs daily on its own; the button below forces a run now.

You must be signed in to menards.com in this browser. The first run looks back a year to backfill history; later runs cover the last 14 days. Re-importing an existing receipt is a no-op on the server, so overlap is harmless.
